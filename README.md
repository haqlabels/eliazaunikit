# Eliaza Unique Kitenge Website

This version has:
- Home page with 4 photos
- About page with 2 photos
- New Stock: 10 photos
- Old Stock: 10 photos
- Exactly 2 stock photos per row
- WhatsApp buttons

## Replace photos
Inside the `images` folder, keep these exact names:
`home-1.jpg` to `home-4.jpg`
`about-1.jpg`, `about-2.jpg`
`new-1.jpg` to `new-10.jpg`
`old-1.jpg` to `old-10.jpg`

## Publish free
Upload the folder contents to a GitHub repository, then go to:
Settings → Pages → Deploy from a branch → main → /(root) → Save.
